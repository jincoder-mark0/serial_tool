# UX 점검 보고서 (2026-08-22)

테마·언어팩·레이아웃을 UX 관점에서 점검한 결과. 사용자 지시에 따라 **코드 정독 + 실제 실행**을
병행했다 — 실행 화면 스크린샷 8조합(테마 dark/light × 언어 ko/en × 창 크기 기본/축소,
도구: `tools/ux_capture.py`)을 하위 모델이 육안 판정하고, 정적 코드 점검 3종(테마/언어팩/레이아웃)과
교차 검증했다. 각 결함의 수정은 `tasks/S-019~S-026`으로 등재.

교훈: offscreen 플랫폼은 폰트를 렌더하지 않아 스크린샷 판정에 쓸 수 없다(전 텍스트 공백).
네이티브 플랫폼 캡처로 전환 후 판정 — RULES.md §7로 규칙화됨.

  폴백 제거 시 전 테마 파손 위험 구조. → **S-023**
- **`ThemeManager.apply_theme`가 문서와 달리 color_manager를 호출하지 않음** (import만) —

  `resources/icons/dracula/`는 dark와 byte 동일 사본 8개. + `main_menu_theme_dracula` 키 부재,
  Preferences 테마 콤보 미번역(메뉴와 표기 불일치). → **S-023**
- **"+" 탭 아이콘 테마 전환 미갱신**: `port_tab_panel.py:160` 재호출 연결 없음. → **S-023**
