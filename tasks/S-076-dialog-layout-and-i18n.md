## 목적 (Why)

메인 창은 여러 차례 캡처로 점검했으나 다이얼로그는 한 번도 열어 보지 않았다.
4개 다이얼로그 × 4테마 × 2언어 = 32장을 캡처해 확인했다.

## 발견 1 — 파일 전송 다이얼로그가 뭉개져 있었다

`setFixedSize(450, 250)`인데 내용이 요구하는 높이는 **266px**(offscreen 실측,
네이티브는 더 크다). 파일 선택 행·전송 버튼·진행률이 25px 남짓에 **겹쳐 그려졌다.**
4테마 × 2언어 전부 동일 — 테마나 번역 문제가 아니라 구조 문제였다.

`setFixedSize` → `resize` + 최소 폭으로 바꿨다. `resize()`는 레이아웃이 요구하는 최소
크기 아래로 클램프되지 않으므로 번역이 길어져도 잘리지 않는다. 수정 후 450×331로
정상 렌더(육안 확인).

같은 이유로 About 다이얼로그의 `setFixedSize(400, 300)`도 풀었다. 지금은 들어맞지만
번역이나 폰트 크기가 바뀌면 같은 일이 난다.

## 발견 2 — 폰트 설정의 표준 버튼이 번역되지 않았다

`QDialogButtonBox`의 OK/Cancel/Apply는 Qt 기본 문구를 쓴다. Preferences는 직접 번역해
넣고 있었는데 **폰트 설정만 빠져 있어** 한국어 화면에 영문이 남았다.
`font_btn_ok/cancel/apply` 키를 추가하고 같은 방식으로 넣었다(확인/취소/적용).

## 하드코딩 문자열 점검 결과

정적 스캔에서 3건이 나왔으나 모두 정당하다고 판단해 두었다.

- `font_settings_dialog.py`의 고정폭 미리보기 샘플 — 폰트 모양을 보이는 것이 목적인
  고정 ASCII 문자열이라 번역 대상이 아니다.
- 언어 콤보의 `"English"` — 언어 이름은 그 언어로 적는 것이 관례다.
- 구분자 입력의 `"0x00 or \\r\\n"` 플레이스홀더 — 형식 예시.

## 테스트에서 조정한 것

`tests/test_dialog_layout_and_i18n.py`가 세 가지를 고정한다: 높이 부족, 고정 크기 사용,
표준 버튼 미번역.

크기 판정은 **높이만** 본다. offscreen에는 시스템 폰트가 없어 텍스트 위젯(미리보기
QTextEdit 등)의 **폭** 힌트가 비정상적으로 크게 나온다(실측: font_settings 999px —
네이티브 캡처에서는 600px로 멀쩡하다). 높이는 행 수로 결정되어 그 왜곡이 없고,
실제 결함도 높이 쪽이었다.
