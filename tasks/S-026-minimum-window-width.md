## 목적 (Why)

실행 실측(tools/ux_capture.py): MainWindow `minimumSizeHint`가 **ko 1458×735 / en 1435×735** —
1366×768 노트북 화면에 창이 들어가지 않는다. 시리얼 도구는 현장 노트북 사용이 잦아
실사용 차단 수준의 결함이다 (근거: doc/ux_audit_20260822.md 요약).

## 원인 구조 (정적 점검 확인)

- `view/widgets/port_settings.py:172-236` — 프로토콜/포트/보드레이트/데이터/패리티/정지/흐름
  라벨+콤보 10개가 전부 `setFixedWidth`/`setMinimumWidth` 고정이고 행에 줄어들 수 있는
  위젯이 없음 → `PortPanel`의 minimumSizeHint가 좌측 섹션 최소폭을 지배.
- 우측 섹션(매크로 테이블)도 컬럼 최소폭 합이 크다.
- 스플리터는 `setCollapsible(0, False)`라 좌측이 사라지진 않지만 줄지도 못한다.
- (S-019 수행 중 실측, 2026-08-22) RX 로그 툴바도 같은 구조: 컨트롤 총합 요구 폭이 패널 폭을
  넘어 stretch가 0으로 수렴하고, 하한이 없는 검색창(`data_log.py:148` — 상한 200만 존재)이
  **35px까지 축소**되어 placeholder가 "..."만 보인다. 검색창에 `setMinimumWidth`를 주는 것만으로는
  최소 창 폭이 더 커지므로, 툴바 축약(아이콘화/2행화)과 함께 결정할 것.

## 결정할 것 (상위 모델)

1. 목표 최소 크기 (제안: 1280×720 — 1366×768에서 태스크바 감안 여유 확보).
2. 축약 방식: ① 포트 설정 2행을 3행으로 재배치(축소 시), ② 라벨을 아이콘/툴팁으로 축약,
   ③ 콤보 최소폭 하향+Elide, ④ 우측 섹션 접기 기본화 — 조합 선택.
3. README §1.2 "컴팩트한 2줄 포트 설정 레이아웃" 서술과의 정합 (2줄 유지가 요구인지).
